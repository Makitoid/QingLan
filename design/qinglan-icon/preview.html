方案 A「出于蓝」。一笔白色从半透明的蓝环内部生出，穿过环上的缺口、越过环的外沿 —— 青，出于蓝而胜于蓝：学生从教师与平台这里长出去，长得比来源更亮。 这一笔的折角同时是判题的 Accepted 勾，环与出锋合起来读作字母 Q。 整套 UI 的品牌色由后台 brand_color 经 chroma 在 LAB 空间生成色阶， 所以图标只用单一色相的纵向渐变 + 白色三级透明度，后台换色不破图。

规范

网格64 × 64 设计单位；容器四周留 2 单位给宿主投影（favicon 版满幅，圆角 13）
容器圆角矩形 60 × 60，rx = 15（边长的 25%，Fluent 2 App Icon 比例）
容器填充纵向 4 段单色相渐变，stops 0 / .16 / .52 / 1 = 提亮 46% / 提亮 22% / 基准 / 压暗 15%，顶部高光烘进渐变里，不叠半透明白层（会留接缝）
内描边1.6 单位、白色 30%，仅 ≥32 px 出现
笔画6.5 单位，圆头端点 + 圆角连接（对应 Fluent 16/20/24 图标的视觉权重）
蓝环圆心 (31,36) r=12.5，自 −10° 顺时针 300°，右上留 60° 缺口供青笔穿出；白色 55% 不透明度
青笔M26 33 → L28.5 38.5 → L47.6 19.3；起点在环内，45° 穿出缺口，末端距圆心 23.55 单位 > 环外沿 15.75 单位；白色实心
层级只用两级白：环 .55（承接）→ 笔 1.0（胜出）。不引入第二色相，保证换任何品牌色都成立
小尺寸≤24 px 改由笔画粗细承担层级：环 5.0 单位 / .85，笔 9.0 单位，去内描边。同权重时环与勾会在 16 px 糊成一团
对比度实心笔 / 容器 = 3.87:1（≥3.0 非文本底线）；提亮 18% 后容器 / 浅色页 = 3.48:1，容器 / 深色面 = 4.46:1
导出design/qinglan-icon/render.ps1（PowerShell + GDI+，无外部依赖）产出 png/ 12 档 + 校验图；$env:QL_TONE 调提亮量
